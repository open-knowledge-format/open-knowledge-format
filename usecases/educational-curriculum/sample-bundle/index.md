# Concepts

- [00 — Legacy unit](00-legacy-unit.md) — Retired unit under a previous vocational framework.
- [01 — Curriculum catalog](01-curriculum-catalog.md) — Normative learning outcomes and assessment criteria from the official decree.
- [02 — Learning activity](02-learning-activity.md) — Agent-drafted, teacher-verified classroom lab.

# How to read this bundle

1. Start at the [curriculum catalog](01-curriculum-catalog.md): it is the read-only normative layer.
2. Read the [learning activity](02-learning-activity.md) to see how a classroom lab cites the catalog with file-relative links and `x-okfedu-covers-criteria`.
3. Open the [legacy unit](00-legacy-unit.md) to see the `status: deprecated` + `superseded_by` law-transition pattern.
